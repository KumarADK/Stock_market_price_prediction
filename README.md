 Stock Market Price Prediction and Classification using Random Forest
 What is it?
This project simulates stock market data and applies two types of machine learning models:

Random Forest Regressor – to predict the closing stock price.

Random Forest Classifier – to predict whether the stock price will go up or down the next day.

The project includes data generation, visualization, model training, evaluation, and prediction analysis.

What did I use?

Libraries & Tools:

NumPy & Pandas – for data manipulation and synthetic data generation.

Matplotlib – for data visualization.

Scikit-learn – for model building, training, and evaluation.

Algorithms:

RandomForestRegressor for predicting continuous values (stock price).

RandomForestClassifier for predicting binary classes (price up/down).

What did I learn?
How to generate realistic synthetic stock data using a random walk method.

The process of preprocessing data for both regression and classification tasks.

How to apply and train Random Forest models effectively.

Techniques for evaluating model performance using:

Mean Squared Error (MSE) for regression.

Confusion Matrix and Classification Report for classification.

The importance of visualizing results to understand model behavior and data trends.

What did I measure?
Regression Metrics:

Mean Squared Error (MSE): Measures how close predicted prices are to actual prices.

Lower MSE indicates better performance.

Classification Metrics:

Confusion Matrix: Shows the number of correct and incorrect predictions.

Precision, Recall, F1-score: Evaluates the accuracy and reliability of the up/down predictions.
